Why keep calendar copies

Find what changed in a schedule.

Meetings move. Events disappear. A provider may be unavailable when you need an earlier plan.

Calendar Snapshotter compares each local copy. It marks added, moved, and cancelled events for review.

How it works

Save. Compare. Restore.

  1. 01

    Save a calendar copy

    Import a calendar file (.ics). Existing license holders can schedule copies from a calendar server (CalDAV).

  2. 02

    Review changes

    See added, moved, and cancelled events in a short list.

  3. 03

    Restore selected events

    Export selected earlier events to a calendar restore file (.ics).

Privacy and limits

Calendar copies stay in your local vault.

Encrypted vault
Calendar copies and saved sign-in details are encrypted before local storage.
No calendar uploads
The app has no analytics or third-party calendar processing.
Standard restore format
Restore files use the standard calendar format (.ics).
Important limit
Scheduled copies run only while Calendar Snapshotter is open.
Pausednew license sales

Scheduling license

Scheduling sales are paused.

New licenses are not currently for sale. Existing license holders can schedule calendar server copies while the app is open.

Manual calendar copies, change review, full archive backup, and restore files remain free.
